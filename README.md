# Zama FHE Smart Contracts

This repository contains privacy-preserving smart contracts built using
Zama’s Fully Homomorphic Encryption (FHE) model.

## Contracts
- ZamaEncryptedCounter.sol
- ZamaEncryptedVault.sol
- ZamaEncryptedVoting.sol
- ZamaEncryptedDAO.sol

## Purpose
To demonstrate real developer usage of FHE in Solidity and build
verifiable on-chain privacy primitives.

Built by GreenBasket Labs.
